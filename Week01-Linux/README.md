Learn the fundamentals of Linux administration and the Bash shell while configuring a development server.

## Business Scenario

CloudCore Solutions needed a standardized Linux development server for engineers to practice administration and prepare for future AWS deployments.

---

## Challenges

- Learned why "Permission denied" occurs.
- Practiced troubleshooting command syntax.
- Learned how Bash interprets commands.
- Worked with file permissions and sudo.

---

## Lessons Learned

Linux rewards precision. Small syntax errors, such as missing spaces, can completely change how a command behaves. Reading error messages carefully is one of the most valuable troubleshooting skills.
